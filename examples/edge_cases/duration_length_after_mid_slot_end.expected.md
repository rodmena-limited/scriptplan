# duration_length_after_mid_slot_end

a ends 09:40. A duration task after it starts at 09:40 and lasts 2 hours of calendar time: 11:40.
A length task counts working time; 09:40-11:40 is inside Monday's 09:00-17:00, so it also ends 11:40.
0.10.0 and 0.10.1 reported both as 09:00-11:00, starting before a finished (issuedb #13).

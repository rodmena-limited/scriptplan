# gaplength_on_project_calendar

a runs Mon 08:30-12:30. A gaplength is working time on the project's calendar, here the default
09:00-17:00: Mon 12:30-17:00 is 270 minutes and Tue 09:00-12:00 the other 180, so b may start Tue 12:00. It
works 12:00-17:30 (330 minutes) and Wed 08:30-11:00 (150). The hour-level reference scheduler gives the same
start.

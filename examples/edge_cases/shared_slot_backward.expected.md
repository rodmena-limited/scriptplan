# shared_slot_backward

The same three tasks, each alap with end 17:00. Tasks of equal priority are placed larger effort first (path criticalness), and equal efforts in
declaration order, so the order is t0, t2, t1.
Each is placed as late as the desk allows: t0 17:00 - 40 = 16:20; t2 ends where t0 begins,
16:20 - 40 = 15:40; t1 15:40 - 13 = 15:27.
